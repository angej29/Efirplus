# Ефір — IPTV-плеєр для Android і Android TV

## Як отримати APK (через GitHub, без встановлення програм)

1. Зареєструйтесь або увійдіть на github.com.
2. Натисніть **+ → New repository**, введіть назву (наприклад `efir`) і натисніть **Create repository**.
3. На сторінці нового репозиторію натисніть посилання **uploading an existing file**.
4. Перетягніть у вікно **весь вміст** розпакованої папки `Efir` (разом із папками `.github`, `app`, `gradle`), а не саму папку. Натисніть **Commit changes**.
5. Відкрийте вкладку **Actions**. Збірка запуститься автоматично й триватиме 5–8 хвилин.
6. Коли біля збірки з'явиться зелена галочка, на головній сторінці репозиторію праворуч у розділі **Releases** буде файл `Efir-N.apk`. Відкрийте цю сторінку з телефона або приставки, завантажте APK і встановіть (дозвольте встановлення з невідомих джерел).

Наступні версії ставляться поверх попередніх: ключ підпису постійний.

## Керування

**Телефон**
- Тап по каналу: дивитися. Довгий тап: додати в обране або прибрати з нього.
- У плеєрі:
  - тап показує панель;
  - подвійний тап відкриває список каналів;
  - свайп вліво/вправо перемикає канал;
  - свайп вгору/вниз зліва змінює яскравість, справа — гучність.
- Кнопка «PiP» або кнопка «Додому» під час перегляду вмикає картинку в картинці.

**Пульт (Android TV)**
- ▲▼ і CH+/CH−: попередній/наступний канал.
- OK або ◄: список каналів. ► або Menu: меню (обране, формат кадру).
- Утримання OK на каналі: додати в обране.

## Можливості
- Кілька плейлистів (посилання або файл M3U/M3U8).
- Групи з плейлиста, «Обране», «Недавні», пошук.
- Телепрограма XMLTV (зокрема .gz): «зараз» і «далі» з прогресом.
- HLS, MPEG-TS та інші потоки (ExoPlayer). Підтримуються User-Agent і Referer із плейлиста (`#EXTVLCOPT`, `|User-Agent=`).
- Автоперепідключення при обриві потоку.
